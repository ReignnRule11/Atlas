# Atlas

**Professional Economy Infrastructure**

Atlas connects professional identity, demonstrable proof of work, opportunity, collaboration, intelligence, and economic activity.

> Turn professional capability into economic opportunity.

## Product principles
- Evidence over unsupported claims.
- Transparent, explainable reputation—not opaque scores.
- Privacy and user control by default.
- Real integrations only; no fabricated opportunities or verification.
- Start with Identity + Proof, then expand deliberately.

## Initial focus
Builders, engineers, designers, product professionals, founders, and independent professionals.

## Architecture direction
- Web: Next.js + TypeScript
- API: FastAPI + Python
- Data: PostgreSQL + SQLAlchemy
- Deployment: Vercel and Render (initial target)
- CI: GitHub Actions

Atlas is being built incrementally with reviewable pull requests, automated checks, and verified deployment evidence. Features are not considered shipped until implemented and tested.
